# Сохранённые результаты работы LLM-шага

Здесь лежит вывод шага, снятый с реальных запусков. Нужен для двух случаев: посмотреть формат
результата, не поднимая модель, и провести занятие, если модель на машине не запустилась.

| Файл | Что это |
|---|---|
| `triage-green.md` | разбор зелёного прогона: 22 теста, падений нет |
| `triage-failed.md` | разбор `samples/surefire-failed`: три падения разной природы |
| `triage-prompt-example.txt` | промпт, который ушёл в модель во втором случае — после подстановки данных и санитизации |
| `generated-workflow-example.yml` | черновик конвейера, сгенерированный моделью в демо 2 |

Снято 26.08.2026 на `llama3.1:8b` с промптом версии 2.1.

Это **снимок прошлого запуска**, а не живой результат: модель может ответить иначе, формат при этом
не изменится — его держит схема `schema/triage.schema.json`.
